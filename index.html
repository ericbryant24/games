Deck ChairArcade

Browser games that load fast and play with your thumbs.

    About

    Everything here is a static page — plain HTML, CSS and JavaScript served straight from GitHub Pages. No accounts, no ads, no installs. Games are built portrait-first so they work one-handed-ish on a phone, and they also take keyboard input on desktop.

    Add sound with the volume key, and add a game to your home screen for a full-screen run.
