Deck ChairArcade

Browser games that load fast and play with your thumbs.

    About

    Everything here is a static page — plain HTML, CSS and JavaScript served straight from GitHub Pages. No accounts, no ads, no installs. Games are built portrait-first, so a phone held upright with a thumb either side is the intended way to play, and they take keyboard input on a desktop too.

    Add one to your home screen and it runs full screen with no browser furniture.
